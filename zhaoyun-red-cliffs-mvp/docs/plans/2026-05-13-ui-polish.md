# UI 精緻化計劃

> **For Claude / Codex:** 實作前請先讀 README.md 與 docs/project-progress.md 了解專案背景。
> 完成後執行 `python3 -m pytest tests/test_zhaoyun_mvp.py tests/test_sprite_integration.py -v` 確認 **23/23 通過**。

**目標：** 把目前功能型 HUD 升級為接近商業動作遊戲的精緻 UI，參考風格：韓系橫向動作 RPG（如 DNF）——深色面板、金色邊框、大字體、大頭像框。

**架構：**
- HUD 全部在 `renderer.js` 的 `render()` 函式後半段（第 704 行起），使用 Canvas 2D API 繪製
- AI 產圖素材放在 `zhaoyun-mvp/assets/ui/`，透過 `new Image()` 載入，有圖用圖，沒圖 fallback 到純 Canvas 繪製
- 觸控按鈕外觀在 `styles.css`（DOM 元素，非 Canvas）

**技術棧：** Vanilla JS + HTML5 Canvas，無任何框架

## 注意事項

- `_titleCanvas` 是 offscreen cache，**改了 `buildTitleCanvas()` 後必須把 `_titleCanvas = null` 清掉**，否則仍會顯示舊版。在 `buildTitleCanvas()` 開始前加一行 `_titleCanvas = null;` 讓下一幀重建即可，或在 `startGame()` 時清除。
- `uiImg()` 函式回傳 `null` 時要走 fallback，**確保沒有 AI 圖也能正常運作**（測試環境不會有 UI 圖）
- 測試中 `test_screenshot_title` 和 `test_screenshot_running` 只驗截圖非空，不驗畫面內容，所以視覺改動不影響測試通過
