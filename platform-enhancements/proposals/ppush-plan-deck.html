核心構想 · 重新觸及

藉由推播，找回流失的玩家

玩家離站後，站內訊息與橫幅再也碰不到他。推播是其一能主動出現在玩家鎖定畫面的管道 —— 在對的時機，把他帶回來。

  • 🔔
    離站也能觸及：直接出現在鎖定畫面／桌面通知，不需開啟 App 或站台。
  • 🎯
    在對的時機軟性引導：首存、出金、贏錢等高意願時刻送出，同意率最高。
  • 🤝
    接 CRM 既有分群：對不同玩家群體，送不同內容與優惠，差異化喚回。

CRM 協作

接上 CRM 既有分群，做差異化推播

CRM 先前已為站台分類出許多玩家群體。推播不必重做分群——直接沿用 CRM 群體，對不同群體設定不同的內容與時機。

🚨 流失風險
喚回推播：輸錢離站後，於對的時機送出回饋／優惠提醒。
😴 休眠玩家
喚醒推播：久未登入，推送回歸禮／新活動。
💎 高價值玩家
專屬推播：VIP 活動、賽事與限定優惠。
🌱 新註冊玩家
引導推播：首存提醒、新手任務。

關鍵限制

推播的開關，握在使用者手上

推播是否送達由使用者決定。玩家一旦拒絕瀏覽器通知，功能就完全失效；Chrome 被「封鎖」後更是再也彈不出系統視窗。關鍵不是「能不能推」，而是「怎麼讓玩家願意開」。

✕ 太早 / 隨機跳出系統視窗
一進站就彈窗 → 玩家反射性封鎖 → 永久失效。封鎖後任何授權呼叫都被瀏覽器靜默忽略，這個玩家再也救不回來。
✓ 在對的時機，軟性引導
先用站內軟性詢問 → 說明好處後再請求 → 同意率高、保留退路。「稍後」不等於「永不」，絕不硬碰系統封鎖。
對的時機 ▸ 💰 存款成功後 🏆 中獎 / 領獎時 🎁 領取優惠時 ⚽ 關注賽事開賽前
對的時機 · 軟性引導

什麼是「對的時機」？

把授權邀請包裝在玩家的成就感與情緒高峰時刻，而不是一進站就打擾——同意率最高，也最不傷體驗。

場景 A存款、出款成功後
出入金代表信任高峰，順勢提供「到帳通知」。
場景 B贏得賽事時
領獎是情緒高峰 — 轉換率最高之一。
場景 C領取優惠時
剛領優惠，正想「別錯過下一檔」— 順勢開通知。
場景 D關注賽事開賽前
已關注＝有期待，用開賽提醒自然換授權。

標準模式 vs 隱私模式

同一則推播，通知欄裡的兩種呈現 —— 差別只在「標準 / 隱私」一個選項。

  • 標準模式：平台名稱、賽事圖片、賠率與操作按鈕全露出 —— 點擊力最強，但旁人一眼就看出是博彩平台的通知。
  • 隱私模式：標題／內文改為中性字樣，圖片與按鈕一律不發送 —— 內容完全遮蔽，真實細節只有打開站台才看得到。
  • ⚠來源列「bj.com」無法隱藏 —— Chrome 政策限制。
技術實施 · 各端作業

設計、前端、後端各自要做什麼？

P1 首發垂直切片：首次出金 / 首頁 banner 觸發 → soft-ask 邀請 → 當場系統授權 → granted 綁 token；且啟動不再自動跳提示。P1 首發P2 次期P3 後期

🎨 設計
  • P1設計「軟性詢問」彈窗的畫面與文案（出金版、首頁 banner 版兩種）
  • P1訂出標準／隱私兩種通知的外觀規範（標題、內文、圖示、圖片、按鈕）
  • P3設計設定頁的「通知開關」區塊與分類偏好頁
  • P3替「已封鎖推播」的玩家，設計重新開啟的引導畫面
💻 前端 · Angular
  • P1拿掉「一進站就跳系統授權窗」；改成只有玩家同意過，才在背景自動維持推播連線
  • P1判斷每位玩家「能不能收、是否已同意、是否被封鎖」（含 iPhone／Safari 特例），並在關鍵時機重新確認
  • P1先「軟性詢問」再正式請求授權，並控管打擾次數（出金問 1 次、首頁 banner 每 7 天、最多 3 次）
  • P1把軟性詢問接到兩個時機：首次出金成功後、首頁 banner
  • P2收到後端送來的通知後，正確顯示給玩家看（例如「到帳提醒」）
  • P3做出設定頁的通知開關，讓玩家自選要收哪些類型、以及標準／隱私模式
⚙️ 後端 · Java 負擔小
  • P1記住玩家裝置的推播憑證 ✅ 現成、免改（支援多裝置、30 天自動更新）
  • P1加一個「是不是第一次出金」的標記（很簡單 · 看出金筆數是否＝1）
  • P2跟前端約好通知的資料格式，並串接 FCM（Google 推送服務）發送
  • P3儲存玩家的通知偏好設定（新增／查詢／修改／刪除）
⚠ 跨團隊待敲定：pilot 品牌（DB TRACKINGSETTING type=7）· notificationType 整數／字串 · 追蹤機制（GA.gtag vs EventQueue）。  ✦ P1 後端幾乎免改 — token API 已現成、出金旗標低工，主要工作量落在前端與設計。
結語 · Conclusion

運用推播，促使玩家回流

推播真正的價值，是在玩家離開站台、正在做別的事時——看影片、滑社群、甚至手機待機——我們依然能在他的鎖屏與通知欄悄悄出現，用一句話把他吸引回來。這是離站之後，其一能主動觸及玩家的管道。
