# SecurePlay Design System

反向還原 SecurePlay 行動 App 的 Figma 設計系統。

## 資料夾說明

| 資料夾 | 用途 |
|--------|------|
| `screenshots/` | 放 SecurePlay App 的截圖（亮色 + 暗色模式都要） |
| `assets/` | 其他素材（icon、字體、品牌資源等） |

## 相關文件

- 設計規格：`../docs/superpowers/specs/2026-06-26-secureplay-design.md`
- 實作計畫：`../docs/superpowers/plans/2026-06-26-secureplay-design-system.md`

## 截圖命名建議

```
screenshots/
├── light/        ← 亮色模式截圖
│   ├── 01-home.png
│   ├── 02-login.png
│   └── ...
└── dark/         ← 暗色模式截圖
    ├── 01-home.png
    ├── 02-login.png
    └── ...
```
